# Claude Code Subagents and Agent Skills

## Chapter Content Generation Agent

This agent is responsible for generating educational content for chapters in the Physical AI & Humanoid Robotics textbook.

### Purpose
- Generate comprehensive, technically accurate content for textbook chapters
- Ensure content aligns with learning objectives and educational goals
- Adapt content complexity to target audience level

### Skills
- `chapter-gen`: Generate complete chapter content with proper structure
- `section-expand`: Expand specific sections with detailed explanations
- `concept-illustrate`: Create illustrations and examples for complex concepts

### Usage
The agent can be invoked to generate new chapters or expand existing content based on educational requirements.

## Code Example Verification Agent

This agent validates code examples in the textbook to ensure they are correct and executable.

### Purpose
- Verify code examples for syntax correctness
- Check code compatibility with specified libraries and versions
- Ensure examples follow best practices

### Skills
- `code-verify`: Verify syntax and correctness of code examples
- `dependency-check`: Validate required dependencies and imports
- `execution-test`: Test code examples in appropriate environments

### Usage
The agent reviews all code examples in chapters to ensure they function as described.

## Exercise Generation Agent

This agent creates exercises and problems for students to practice concepts.

### Purpose
- Generate practice exercises aligned with chapter content
- Create problems of varying difficulty levels
- Include solution guides and grading rubrics

### Skills
- `exercise-gen`: Generate exercises based on chapter content
- `difficulty-level`: Adjust exercise difficulty based on user profile
- `solution-create`: Create detailed solutions and explanations

### Usage
The agent creates exercises for each chapter to reinforce learning objectives.

## Glossary Extractor Agent

This agent extracts and maintains technical terms and definitions.

### Purpose
- Identify and define technical terminology
- Maintain consistent terminology throughout the book
- Create comprehensive glossary entries

### Skills
- `glossary-extractor`: Extract technical terms and definitions
- `term-consistency`: Ensure consistent use of terminology
- `definition-update`: Update definitions based on context

### Usage
The agent maintains the glossary and ensures consistent use of technical terms.

## Diagram Assistance Agent

This agent helps create and describe diagrams and visual aids.

### Purpose
- Generate descriptions for diagrams and figures
- Create SVG code for simple diagrams
- Describe complex visual concepts in text

### Skills
- `diagram-assist`: Create and describe diagrams
- `svg-generator`: Generate SVG code for simple diagrams
- `visual-describe`: Describe visual content for accessibility

### Usage
The agent assists in creating visual aids that complement textual content.

## Citation Checker Agent

This agent verifies and maintains proper citations and references.

### Purpose
- Check citations for accuracy and completeness
- Verify reference formatting
- Ensure proper attribution of sources

### Skills
- `citation-checker`: Verify citations and references
- `format-check`: Ensure proper citation formatting
- `source-verify`: Validate source availability and accuracy

### Usage
The agent maintains the integrity of citations and references throughout the textbook.
