Appendix E - Glossary of Terms

Introduction to the Glossary​

This glossary provides definitions for key technical terms, acronyms, and concepts used throughout "Physical AI & Humanoid Robotics — A Complete Hands-On Course." As you delve into the interdisciplinary fields of robotics, artificial intelligence, and physical computing, you will encounter a rich vocabulary. This appendix serves as a quick reference to help you solidify your understanding and navigate the terminology with confidence.

Glossary​

A

  • Actuator: A component of a machine that is responsible for moving or controlling a mechanism or system. It converts energy into mechanical force, e.g., a motor or a hydraulic cylinder.
  • Alembic: A lightweight database migration tool for SQLAlchemy. It allows for versioning your database schema and applying changes incrementally.
  • Artificial Intelligence (AI): The simulation of human intelligence processes by machines, especially computer systems. These processes include learning, reasoning, problem-solving, perception, and language understanding.
  • Automatic Speech Recognition (ASR): A technology that enables the recognition and translation of spoken language into text. Also known as speech-to-text.
  • Autonomous Robot: A robot that can perform tasks or behave in an environment without continuous human guidance.

B

  • Behavior Tree (BT): A mathematical model of plan execution used in computer science, robotics, and video games. It structures decision-making into a tree of tasks that are executed in a top-down fashion.
  • Black: An uncompromising Python code formatter that ensures consistent code style by reformatting code automatically.
  • BNO055: A System in Package (SiP) that integrates a triaxial 16-bit gyroscope, a triaxial 14-bit accelerometer, a triaxial geomagnetic sensor, and a 32-bit ARM Cortex-M0+ microcontroller running Bosch Sensortec sensor fusion software.

C

  • ChatGPT: A large language model developed by OpenAI, trained for conversational AI. It can answer questions and engage in dialogue across a wide range of topics.
  • Claude Code: Anthropic's official CLI (Command Line Interface) for Claude, designed to assist users with software engineering tasks through an interactive agent.
  • Cognitive Planning: The ability of an intelligent agent (robot, AI) to reason about its goals, available actions, and environmental state to construct a sequence of steps to achieve a desired outcome.
  • Colcon: A command-line tool used to build multiple software packages from source, especially prevalent in ROS 2 development.
  • Computer Vision: A field of artificial intelligence that trains computers to interpret and understand the visual world from images and video.
  • Continuous Integration (CI): A software development practice where developers regularly merge their code changes into a central repository, after which automated builds and tests are run.
  • CUDA: A parallel computing platform and application programming interface (API) model developed by NVIDIA for its GPUs, enabling general-purpose computing.
  • cuDNN: The NVIDIA CUDA Deep Neural Network library, a GPU-accelerated library of primitives for deep neural networks.

D

  • Docusaurus: An open-source static site generator that helps you build optimized websites quickly, often used for documentation sites, blogs, and product landing pages.
  • Digital Twin: A virtual model designed to accurately reflect a physical object, process, or system. Used in robotics for simulation, testing, and monitoring.
  • DKMS (Dynamic Kernel Module Support): A program/framework that allows kernel modules to be installed in such a way that they will be automatically rebuilt when a new kernel version is installed.

E

  • Edge Computing: A distributed computing paradigm that brings computation and data storage closer to the sources of data, improving response times and saving bandwidth.
  • Embedded System: A computer system—a combination of a computer processor, computer memory, and input/output peripheral devices—that has a dedicated function within a larger mechanical or electrical system.
  • Embodied Intelligence: A branch of AI that focuses on how intelligence arises from the interaction of a physical body with its environment, rather than purely abstract computation.
  • ESLint: A pluggable linting utility for JavaScript and JSX, used to identify and report on patterns found in ECMAScript/JavaScript code.

F

  • FastAPI: A modern, fast (high-performance) web framework for building APIs with Python 3.7+ based on standard Python type hints.
  • FFmpeg: A complete, cross-platform solution to record, convert, stream, and play multimedia content.
  • Function Calling (LLMs): A feature in some LLMs that allows them to detect when a user is asking to perform an action (e.g., call a function, use a tool) and respond with a structured object (e.g., JSON) describing the function to be called and its arguments.

G

  • Gazebo: A powerful 3D robot simulator that accurately and efficiently simulates populations of robots in complex indoor and outdoor environments.
  • Gemini: A family of multimodal large language models developed by Google AI, designed for understanding and generating content across various modalities, including text, code, audio, image, and video.
  • Grasping: The act of a robot manipulating an object by holding it, typically using an end-effector (gripper) on a robotic arm.
  • Grounding (LLM): In robotics, the process of connecting abstract concepts, words, or plans generated by an LLM to concrete perceptions and actions in the physical world.

H

  • Humanoid Robot: A robot with its overall body shape built to resemble the human body, such as having a torso, a head, two arms, and two legs.

I

  • IMU (Inertial Measurement Unit): An electronic device that measures and reports a body's specific force, angular rate, and sometimes the orientation of the body, using a combination of accelerometers, gyroscopes, and often magnetometers.
  • Inverse Kinematics (IK): The mathematical process of calculating the joint parameters (angles or positions) that are needed to achieve a desired pose (position and orientation) for the end-effector of a robotic arm.
  • Isaac Sim (NVIDIA Isaac Sim): A scalable robotics simulation application and synthetic data generation tool built on NVIDIA Omniverse. It accelerates robotics development, testing, and training.

J

  • JetPack SDK (NVIDIA JetPack SDK): NVIDIA's comprehensive software stack for the Jetson platform, including Linux for Tegra (L4T), CUDA, cuDNN, TensorRT, and other developer tools.
  • Jetson Orin Nano/NX (NVIDIA Jetson Orin Nano/NX): Embedded AI computing boards from NVIDIA designed for high-performance AI at the edge.

K

  • Kinematics: The branch of classical mechanics that describes the motion of points, bodies (objects), and systems of bodies (groups of objects) without considering the forces that cause them to move.

L

  • Large Language Model (LLM): A type of artificial intelligence program that can recognize and generate human-like text. LLMs are trained on vast amounts of text data and can perform various natural language processing (NLP) tasks.
  • librealsense SDK: Intel's open-source SDK for their RealSense depth cameras, providing API access and tools for camera configuration and data streaming.
  • LIDAR: A method for measuring distances by illuminating the target with laser light and measuring the reflection with a sensor. Commonly used for 3D mapping and navigation.
  • Locomotion: The act or power of moving from place to place, especially in the context of robot movement (e.g., walking, rolling, flying).
  • Long-Term Support (LTS): A software release strategy where a version of software is maintained for a longer period than standard releases, offering stability and extended bug fixes.

M

  • Manipulation: The process by which a robot interacts with objects in its environment, typically involving grasping, lifting, moving, and placing.
  • Markdown: A lightweight markup language for creating formatted text using a plain-text editor.
  • MCP Server (Model-Controller-Presenter Server): A specific architectural pattern or framework used in Claude Code to manage and interact with various tools and resources.
  • Multimodal Perception: The ability of an intelligent system to integrate information from multiple sensory modalities (e.g., vision, hearing, touch, language) to form a more complete and robust understanding of its environment.

N

  • Natural Language Understanding (NLU): A subfield of natural language processing (NLP) that deals with machine reading comprehension. NLU enables computers to understand unstructured text by extracting meaning and intent.
  • Navigation2 (Nav2): The ROS 2 navigation stack, providing mobile robots with the ability to autonomously navigate from a starting point to a goal location, avoiding obstacles.
  • Neon Serverless Postgres: A serverless PostgreSQL database service that offers scalability, elasticity, and cost-efficiency.
  • Node (ROS 2): An executable process in ROS 2 that performs computation (e.g., a sensor driver, a controller, an AI algorithm). Nodes communicate with each other using topics, services, and actions.

O

  • Odometry: The use of data from the movement of a robot's actuators (e.g., wheel encoders) to estimate its change in position and orientation over time.
  • OpenAI Whisper: An open-source Automatic Speech Recognition (ASR) model developed by OpenAI, capable of transcribing audio into text in multiple languages and translating them into English.
  • Orchestration Node: A central control node in a robotic system (often in ROS 2) that coordinates the activities of various other nodes, managing the overall flow of information and execution.

P

  • PEP 8: The official style guide for Python code, providing conventions for writing readable and consistent Python code.
  • Perception: The process by which a robot senses and interprets information from its environment, typically using sensors like cameras, LIDAR, and IMUs.
  • Physical AI: A branch of artificial intelligence that focuses on intelligent systems embodied in physical forms (robots) that interact with the real world.
  • pip: The package installer for Python, used to install and manage Python software packages.
  • Point Cloud: A set of data points in a three-dimensional coordinate system. In robotics, often generated by depth cameras or LIDAR sensors to represent the shape and structure of objects and environments.
  • Prettier: An opinionated code formatter that supports many languages and integrates with most editors. It enforces a consistent style by parsing code and reprinting it with its own rules.
  • Proprioception: The sense of the relative position of neighboring parts of the body and strength of effort being used in movement. In robots, this is typically measured by encoders on joints.
  • pydub: A Python library for manipulating audio with a simple and easy high-level interface.

Q

  • Qdrant Cloud: A vector similarity search engine that allows for storing, searching, and managing billions of vector embeddings with accompanying payloads.
  • Quaternion: A number system that extends complex numbers, often used in computer graphics and robotics to represent 3D rotations without gimbal lock.

R

  • RAG (Retrieval-Augmented Generation): An AI framework for LLMs that retrieves factual information from an external knowledge base to augment its responses, improving accuracy and reducing hallucinations.
  • rclpy: The Python client library for ROS 2, providing an API for writing ROS 2 nodes in Python.
  • RealSense D435i: An Intel stereoscopic depth camera with an integrated IMU, providing RGB and depth data.
  • Recurrent Neural Network (RNN): A class of artificial neural networks where connections between nodes form a directed graph along a temporal sequence. Used for processing sequential data like speech and text.
  • Reinforcement Learning (RL): A type of machine learning in which an agent learns to behave in an environment by performing actions and receiving rewards or punishments.
  • Robot Operating System (ROS): A flexible framework for writing robot software. It provides a collection of tools, libraries, and conventions that aim to simplify the task of creating complex and robust robot behavior across a wide variety of robotic platforms.
  • ROS 2: The next generation of ROS, redesigned to be more robust, secure, and suitable for production environments, with improvements in real-time capabilities and multi-robot support.
  • rosdep: A command-line tool for installing system dependencies for ROS packages.
  • RViz: A 3D visualization tool for ROS and ROS 2 that displays sensor data, robot models, and planning outputs.

S

  • SDK Manager (NVIDIA SDK Manager): A desktop tool from NVIDIA that guides you through the process of flashing your Jetson module, installing the OS, and setting up the full JetPack SDK.
  • Semantic Search: A data searching technique that takes into account the contextual meaning of search terms, rather than just matching keywords.
  • Sensor Fusion: The process of combining sensory data from disparate sources such that the resulting information is in some sense "better" than would be possible when these sources were used individually.
  • SLAM (Simultaneous Localization and Mapping): A computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.
  • SQLAlchemy: An open-source SQL toolkit and Object-Relational Mapper (ORM) for Python, providing a flexible way to interact with databases.
  • SpeechRecognition (Python library): A library for performing speech recognition, with support for various engines and APIs, both online and offline.
  • Static Site Generator: A tool that generates a full static HTML website from templates and raw data, rather than building pages on demand with a backend server.

T

  • Tactile Sensor: A sensor that measures information from physical contact or touch, providing data on pressure, force, or texture.
  • TensorRT: An SDK for high-performance deep learning inference developed by NVIDIA. It includes a deep learning inference optimizer and runtime that delivers low latency and high throughput.
  • Time of Flight (ToF): A method for measuring distance by timing the travel of a light signal between a sensor and an object.
  • Topic (ROS 2): A named bus over which nodes exchange messages. Topics are a fundamental element of the ROS communication graph.
  • Transformer (Neural Network): A deep learning architecture introduced in 2017, primarily used in natural language processing (NLP) and computer vision tasks. It relies on a self-attention mechanism.

U

  • Ubuntu 22.04 LTS: A popular, free, and open-source Linux distribution based on Debian, known for its user-friendliness and extensive community support.
  • Unity: A cross-platform game engine developed by Unity Technologies, often used in robotics for creating realistic 3D simulation environments.
  • Unitree G1/Go2: Advanced humanoid (G1) and quadruped (Go2) robots developed by Unitree Robotics, known for their dynamic locomotion and open platforms.
  • URDF (Unified Robot Description Format): An XML file format for describing robots in ROS. It defines the robot's kinematics (links and joints) and dynamics, visual properties, and collision properties.
  • Uvicorn: An ASGI web server implementation for Python, known for its speed and asynchronous capabilities, commonly used with FastAPI.

V

  • vcs (Version Control System tools): A set of command-line tools for working with various version control systems (Git, SVN, Mercurial) in a unified way, often used in ROS 2 development.
  • Vector Database: A database that stores data as high-dimensional vectors (embeddings) and allows for efficient similarity searches. Used in RAG systems for retrieving relevant context.
  • venv: A Python module that enables the creation of lightweight virtual environments, each with its own independent set of Python packages.
  • Vision-Language Model (VLM): A type of AI model that combines capabilities of both computer vision and natural language processing, allowing it to understand and generate content across images and text.
  • Visual SLAM: The process of simultaneously building a map of an environment and localizing a robot within that map using only visual input from cameras.

W

  • World Model: An agent's internal representation of its environment, including objects, their properties, relationships, and dynamic behaviors.

This glossary is designed to be a living document. As you progress through the course and encounter new terminology, consider adding it here with your own definitions to further enhance your learning experience.
